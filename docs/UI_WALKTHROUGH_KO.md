# UI 안내와 합성 시나리오

이 문서는 비네트워크 직군 검토자가 화면의 의미를 빠르게 이해하도록 만든 안내입니다. 예시는 모두 합성 파일명과 문서용 주소를 사용하며 실제 운영 성과를 나타내지 않습니다.

## 첫 화면

웹 로그인 화면은 없습니다. 서버 주소에 접근 가능한 내부망 PC에서는 첫 화면이 바로 열립니다.

| 영역 | 사용자가 보는 것 | 의미 |
|---|---|---|
| 운영 요약 | 완료·취소·실패 표본, 현재 업로드/측정/TCP 상태 | 최근 저장 기록과 현재 서비스 상태의 요약이며 전체 네트워크 장애 현황이 아님 |
| 파일 업로드 | 파일, 저장 하위 폴더, 메모 | 허용된 storage root 안에서 진단 자료를 전달 |
| 최근 업로드 | 시간, 파일명, 폴더, 링크 | 저장된 파일과 다운로드 링크 확인 |
| HTTP 측정 | 데이터량/시간, 업로드/다운로드/전체 | 브라우저가 실제 사용하는 HTTP 경로 관측 |
| TCP 측정 | client ZIP, 등록 PC, 측정 방향/시간/stream | HTTP 처리와 분리된 TCP 전송 경로 관측 |
| 세션 초기화 | 브라우저 CSRF session 초기화 | 로그인/로그아웃 기능이 아니라 현재 브라우저의 CSRF session만 새로 만듦 |

## 합성 검토 시나리오

### 파일 전달

- 합성 파일: `sample-diagnostic.txt`
- 합성 폴더: `demo-case-001`
- 합성 메모: `공개 문서용 테스트 파일`
- 기대 결과: 성공 안내, storage root 안의 저장 위치와 다운로드 링크

### 실패 표현

- 차단 파일: `sample.exe`
- 기대 결과: 위험 파일 정책 설명과 다음 조치, 저장 기록 없음

### 네트워크 측정

- 대상: 동일 PC loopback 또는 격리된 테스트 VM
- 기대 결과: 완료/부분 완료/실패를 구분하고 원시 표본을 JSON·CSV·Excel로 제공
- 해석 금지: 표시된 Mbps를 실제 사내 회선 성과나 보장 속도로 표현

## 웹 접근과 CSRF

- 비루프백 주소에서도 접근 토큰 입력 없이 첫 화면을 바로 표시합니다.
- 웹 로그인용 `itd_v1_...` access token은 사용하지 않습니다.
- 상태 변경 요청은 브라우저에 발급된 CSRF 값을 사용합니다.
- TCP 클라이언트 ZIP에 포함되는 짧은 수명의 `enr_v1_...` enrollment token은 별도 기능이며 계속 사용합니다.
- 웹 인증이 없으므로 서버 포트 접근 범위는 Windows 방화벽, VLAN/ACL, VPN 등 네트워크 경계에서 제한해야 합니다.

## 접근성·표현 원칙

- 정상·주의·장애는 색만이 아니라 텍스트로 함께 표시
- 진행 상태는 `aria-live`로 안내
- 결과 표와 버튼에 label/heading 제공
- 운영 요약에 IP, PC 이름, 원시 오류를 노출하지 않음
- 최근 기록과 현재 장애를 혼동하지 않도록 범위 문구 표시

## 화면 자료 정책

공개 screenshot을 추가할 때는 실제 내부 IP/hostname·파일명·메모·조직명·TCP 등록 token을 제외하고 합성 자료임을 caption에 표시해야 합니다. 실제 Mbps나 장비 수를 현장 성과처럼 표현하지 않습니다.

현재 자동화 환경에서 브라우저 화면 캡처가 가능한 경우에만 실제 앱을 합성 데이터로 실행하고 이 정책을 통과한 이미지를 추가합니다.
